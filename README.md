# Hi, I'm Furkan Sağlam

My academic projects explore machine learning, computer vision, Java and Android application development, and computer architecture.

## Selected Projects

- **[MNIST Neural Network from Scratch](https://github.com/dyingmanfs/mnist-neural-network-from-scratch)** — Neural network layers, forward and backward propagation, and SGD with momentum for MNIST classification using HOG features, compared with a PyTorch reference.
- **[Campus Bookstore Management System](https://github.com/dyingmanfs/campus-bookstore-management-system)** — Java Swing application for student and employee management and textbook reservations, with MySQL/JDBC and file persistence.
- **[Smart Attendance OCR](https://github.com/dyingmanfs/smart-attendance-ocr)** — Raspberry Pi attendance prototype using OpenCV and Tesseract to read student cards, with GPIO LED feedback and CSV logging.
- **[Hocam Program](https://github.com/dyingmanfs/hocam-program)** — Collaborative coursework source snapshot: Android Java and PHP/MySQL for managing students, lessons, attendance, and payment records.
- **[Personal Face Recognition](https://github.com/dyingmanfs/personal-face-recognition)** — Educational binary face-classification prototype using ResNet18 transfer learning and a Gradio prediction interface, trained on a small personal dataset.
- **[8-bit CPU in Logisim](https://github.com/dyingmanfs/8-bit-cpu-logisim)** — An 8-bit processor with an ALU, register file, instruction and data memory, branch/jump control, and component test vectors.

## Additional Work

- **[Data Structures and Algorithms in C](https://github.com/dyingmanfs/data-structures-algorithms)** — Hash tables with collision resolution and rehashing, plus weighted directed graphs and DFS route search.
- **[AVR Embedded Projects](https://github.com/dyingmanfs/avr-embedded-projects)** — ATmega128 assembly projects covering arithmetic, timers, interrupts, traffic-light control, and LCD interfacing.

Each repository documents its coursework context, setup requirements, and current limitations.
